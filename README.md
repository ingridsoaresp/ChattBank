# 🏦 ChattBank

A Java web banking application developed as an academic project to simulate basic banking operations through a web interface.

## Overview

ChattBank allows users to authenticate and retrieve banking account information through a simple web application built using Java EE technologies.

This project was developed to practice server-side programming concepts, MVC architecture, database connectivity, and web application development.

## Features

- User authentication
- Account lookup
- Customer account information
- Error handling
- Database connectivity using JDBC

## Technologies

- Java
- JSP
- Java Servlets
- JDBC
- SQL
- Apache Tomcat
- Maven
- HTML
- CSS

## Getting Started

### Requirements

- Java JDK
- Apache Tomcat
- Maven

### Installation

1. Clone this repository.
2. Open the project in IntelliJ IDEA.
3. Configure Apache Tomcat.
4. Update the database path if necessary.
5. Build and run the project.
